If you want to mark it really quick by right clicking it and process it just follow these steps:
1. Press Windows + R.
2. Type shell:sendto and press Enter.
3. Inside the folder that opens, right-click an empty area and choose New → Shortcut.
4. Browse to your TimelineQuickMark.exe.
5. Name the shortcut Process with Timeline Marker.
6. Click Finish.
